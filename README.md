# dotnet-project
NET Web Application with CI/CD using Azure DevOps  Automated Build &amp; Release Pipeline | Infrastructure-as-Code | Azure Web App Deployment

Project Overview: This project is a .NET web application integrated with a complete CI/CD pipeline using Azure DevOps. The application is automatically built, tested, and deployed to an Azure App Service (Web App) using Azure DevOps Pipelines.

The repository includes the application source code, pipeline YAML files, and deployment configuration following best DevOps practices.

Technologies Used: 
.NET / ASP.NET Core
Azure DevOps Pipelines
Build Pipeline (CI)
Release Pipeline (CD)
Azure App Service (Web App)
Azure Repos / GitHub
Azure Service Connection
YAML-based Pipelines
